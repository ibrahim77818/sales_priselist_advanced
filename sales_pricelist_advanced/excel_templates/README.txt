Excel import templates - Advanced Sales Pricelist (Odoo 19)
=================================================
Copies for convenience. They are NOT loaded by the module (not referenced in
__manifest__.py) and have no effect on installation or upgrades.

Inside Odoo, the same files are offered on the import screen
(gear menu ⚙ > Import records > Help), served from static/xls/.

asp_pricelist_rules_basic.xlsx     Sales > Products > Pricelist Rules > Import   (fixed prices: product, unit, packaging)
asp_pricelist_rules_advanced.xlsx  Sales > Products > Pricelist Rules > Import   (all rule types: discounts, formulas)
asp_pricelists_basic.xlsx          Sales > Products > Pricelists > Import        (creates pricelists with rules)
asp_pricelists_advanced.xlsx       Sales > Products > Pricelists > Import        (creates pricelists with rules)

Each workbook has an "Instructions" sheet (English / Arabic) describing every
column, the allowed values and each example row.
